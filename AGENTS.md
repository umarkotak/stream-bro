# Stream Bro agent rules

- Start product development with `.agents/skills/product-engineer/SKILL.md`.
- Use `.agents/skills/caveman/SKILL.md` for short, simple communication.
- Read `.agents/skills/product-knowledge/SKILL.md` before product decisions.
- After a product change, update the product overview and only the affected reference files.
- Keep core knowledge short. Put detail in references so it is loaded only when needed.
- Never start the web app, a preview server, watch mode, or any development server.
- Never run browser, unit, integration, end-to-end, or other tests. The user tests manually.
- After code changes, always run the production build and fix build errors.
