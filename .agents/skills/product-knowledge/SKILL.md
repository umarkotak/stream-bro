# Product Knowledge

Stream Bro is a local-first streaming toolkit for OBS. Its main avatar studios turn camera and optional microphone input into layered PSD animation. The web app lives in `apps/web` and uses Next.js.

## Knowledge rule

- Always update this overview when the product purpose, audience, core stack, or main feature changes.
- Store detailed and changing facts in references, not here.
- Update only affected references.
- Record facts, decisions, open questions, and user TODOs. Remove stale facts.
- Keep each fact in one place.
